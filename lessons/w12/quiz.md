# Quiz

## 1. What is the primary focus of the Diligence competency in the 4D framework?

**Difficulty:** easy

- ✅ A. Ensuring AI collaboration is ethical, safe, transparent, and accountable, recognizing that tools do not exist in a vacuum.  
  *Correct: Diligence governs ethics, data safety, and human accountability.*
- — B. Cleaning computer hardware fans with an electric vacuum cleaner.  
  *Incorrect: vacuum is used metaphorically for isolated social contexts.*
- — C. Maximizing raw script generation speed regardless of safety or privacy risks.  
  *Incorrect: speed without safety directly violates the diligence standard.*

**Correct answer:** A — Ensuring AI collaboration is ethical, safe, transparent, and accountable, recognizing that tools do not exist in a vacuum.

**Explanation:**  
While Delegation, Description, and Discernment focus primarily on productivity and technical precision, Diligence governs the ethical, safety, and accountability dimensions of AI collaboration. It reminds engineers that technology does not operate in a vacuum—every automated script, data pipeline, and generated document has broader implications for security, privacy, and team trust. The B option takes the vacuum metaphor absurdly literally. The C option ignores safety. Diligence ensures that AI speed is always balanced with rigorous human responsibility, protecting organizations from unintended legal, operational, and ethical liabilities.

## 2. What does an engineer practice when exercising 'Creation Diligence'?

**Difficulty:** easy

- — A. Deleting all version control repositories before beginning a project.  
  *Incorrect: deleting repositories destroys code and violates diligence.*
- — B. Drawing artistic pictures on server cases using permanent markers.  
  *Incorrect: Creation Diligence refers to data security, not physical drawing.*
- ✅ C. Evaluating platform data protection policies, training provenance, and security rules before sharing sensitive code.  
  *Correct: Creation Diligence governs tool selection and input data privacy.*

**Correct answer:** C — Evaluating platform data protection policies, training provenance, and security rules before sharing sensitive code.

**Explanation:**  
Creation Diligence is the disciplined practice of vetting AI platforms before engaging with them. Engineers must investigate who owns the data submitted in prompts, verify whether the vendor trains models on user inputs, and ensure data handling complies with company privacy policies and legal regulations. The B and A options are counterproductive absurdities. Practicing creation diligence protects sensitive intellectual property and confidential infrastructure configurations from unauthorized exposure, ensuring that teams familiarize themselves with vendor terms of service before transmitting proprietary source code.

## 6. A developer wants to paste proprietary server API keys into a public AI chat interface. Which diligence principle is violated?

**Difficulty:** medium

- — A. Deployment Diligence, because the API keys will physically dissolve inside the computer case.  
  *Incorrect: key leakage is an input Creation Diligence issue, not hardware melting.*
- ✅ B. Creation Diligence, because uploading sensitive credentials to public models risks severe security leaks and data breaches.  
  *Correct: credential sharing on unvetted platforms violates Creation Diligence.*
- — C. No violation occurs because AI systems automatically pay company cloud hosting invoices.  
  *Incorrect: sharing API keys creates critical security vulnerabilities.*

**Correct answer:** B — Creation Diligence, because uploading sensitive credentials to public models risks severe security leaks and data breaches.

**Explanation:**  
Pasting private API keys, customer database dumps, or proprietary encryption secrets into public AI interfaces directly violates Creation Diligence. Public consumer models may store prompts in logs or use conversation transcripts for future model pre-training, exposing sensitive infrastructure credentials to unauthorized access. The A and C options are nonsensical claims. Engineers practicing Creation Diligence sanitize all prompt inputs, use dedicated enterprise endpoints with zero-retention guarantees, and store secrets in secure local environment variables, thoroughly evaluating the broader security implications. Maintaining strict credential hygiene ensures that automation never compromises corporate infrastructure or customer privacy.
