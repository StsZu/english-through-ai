# Quiz

## 1. What is the primary purpose of 'Product Description' when prompting an AI model?

**Difficulty:** easy

- ✅ A. To clearly define what you want created, specifying formats, deliverables, audiences, and exact style requirements.  
  *Correct: Product Description articulates the exact deliverable and structure.*
- — B. To buy physical packaging boxes from an e-commerce website.  
  *Incorrect: Product Description is a prompt specification, not physical packaging.*
- — C. To delete all conversation history after typing one word.  
  *Incorrect: Product Description enriches context rather than clearing memory.*

**Correct answer:** A — To clearly define what you want created, specifying formats, deliverables, audiences, and exact style requirements.

**Explanation:**  
Product Description focuses on defining the exact final deliverable you expect from the AI assistant. This includes specifying the output format (such as a JSON schema, markdown table, or Python function), the target audience (such as junior developers or executive stakeholders), and tone constraints. The B option confuses prompting with retail merchandise logistics. The C option is nonsensical. By explicitly describing the desired product upfront, you eliminate ambiguity and prevent the model from guessing what kind of artifact you need.

  *Correct: Process Description outlines the execution methodology and sources.*

**Correct answer:** C — It specifies the method, sequential steps, and specific datasets or documentation the AI must draw on to tackle the job.

**Explanation:**  
Process Description provides step-by-step guidance on how the AI should approach and solve your request. You can also specify exact data sources to draw on. The A option is an absurd hardware distraction. The B option is false. Providing clear process constraints prevents models from taking unwanted shortcuts or jumping prematurely to incorrect conclusions. In software refactoring, for instance, defining the sequence of tests and code edits ensures safe, reliable transformations.
