## 9. You are deploying a CLI agent to manage router alerts. Which delegation strategy balances speed with safety?

**Difficulty:** hard

- — A. Grant the agent unrestricted root credentials to reboot and reconfigure routers without logs.  
  *Incorrect: unrestricted live reconfiguration creates severe network failure risks.*
- — B. Prohibit all automated log parsing and force engineers to read raw terminal dumps manually.  
  *Incorrect: manual inspection of thousands of routine logs is inefficient and prone to fatigue.*
- ✅ C. Allow the agent to autonomously categorize logs and draft fixes, but require human intervention before applying firewall changes.  
  *Correct: combines agency for routine tasks with human authorization for critical changes.*

**Correct answer:** C — Allow the agent to autonomously categorize logs and draft fixes, but require human intervention before applying firewall changes.

**Explanation:**  
The optimal strategy distributes work into safe, automated diagnostic pipelines and controlled human approval gates. The CLI agent uses agency to filter routine noise, categorize incident severity, and prepare draft configuration scripts. However, applying changes to live router interfaces remains exclusively human, requiring explicit engineer verification. The A option creates massive operational hazards by removing safety guardrails. The B option forfeits the immense speed of automated log filtering. This hybrid approach ensures high throughput without sacrificing network stability. In mission-critical environments, requiring a human-in-the-loop for production commits prevents accidental network outages and ensures continuous auditability.
