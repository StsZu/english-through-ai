# Speaking — w02: The AI Fluency Framework

Model answers for reading and review. Personal stories and examples are illustrative, not real events.

## 1. Your CLI agent can either execute a fixed Git task or discuss possible solutions with you. Which mode would you choose, and why? Use automation, augmentation, and straightforward.

**Answer:**  
It depends on the task. If the task is straightforward, for example "create a new branch and commit these files", I choose automation, because I already know the exact result I want. If I do not know the best solution yet, I choose augmentation and discuss the options with the agent first. So I use automation for clear tasks and augmentation for open questions.

**Example:**  
When I needed to clean up a messy git history, I did not know the safest way. I discussed rebase and merge with the agent first, and only after that I asked it to run the commands.

## 2. Imagine an AI agent manages alerts from your MikroTik router independently. What decisions should it make alone, and what should require you? Use agency, responsibly, and highlight.

**Answer:**  
With agency, the AI works on its own, so I must set clear limits. It can make simple decisions alone: collect logs, group similar alerts and highlight the most urgent ones for me. It should not change the configuration, block users or restart the router without my approval. This way, the agent saves me time, and I still manage the network responsibly.

**Example:**  
If the agent sees many failed login attempts, it can send me a message with the IP addresses. But I decide whether to add a new firewall rule.

## 3. Do you agree that augmentation can produce better software than automation when requirements are unclear? Give one concrete example. Use augmentation, automation, and reinforce.

**Answer:**  
Yes, I agree. Automation needs a clear task, but when requirements are unclear, I cannot give one yet. With augmentation, the AI and I explore ideas together, ask questions and improve the plan step by step. My knowledge and the AI's suggestions reinforce each other, so the final software usually fits the real need better.

**Example:**  
When I started my typing platform, I did not know how to show progress to students. By discussing it with the AI, I compared a simple chart, a score and a streak, and chose the chart.

## 4. Your typing platform needs new exercises every week. Would you use automation, agency, or both? Defend your choice with a concrete workflow. Use agency, automation, and versatile.

**Answer:**  
I would use both. Automation is good for the fixed steps: take a list of words and create exercises in the same format every week. Agency could help later: an agent could watch students' results and prepare new exercises for their weak letters on its own. The AI is versatile, but I would still check the exercises before I publish them.

**Example:**  
Every Monday, a script could ask the AI for twenty new sentences with the letters that students often mistype. I review them for five minutes and then publish them.

## 5. Think about preparing for an international drone certification. How could AI fluency improve your preparation without replacing your own learning? Use AI fluency, responsibly, and reinforce.

**Answer:**  
AI fluency means using AI effectively, efficiently, ethically and safely, and this can improve my preparation. I can ask the AI to explain difficult rules in simple words, make practice questions and check my answers. But I must use it responsibly: I study the official materials myself and check the AI's answers against them. The AI should reinforce my learning, not replace it.

**Example:**  
After I read a chapter about airspace, I ask the AI for ten test questions. If it gives a rule that is not in the official handbook, I trust the handbook.
