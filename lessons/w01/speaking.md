## 1. Your CLI agent can edit many files in a git branch. What would you delegate, and what would you keep for yourself? Give one concrete example and use delegation, discernment, and accountable.

**Answer:**  
I would delegate repetitive work to the agent, like renaming variables, updating imports or writing first drafts of tests. I would keep the important decisions for myself: what the feature should do, which branch to merge, and whether the code is safe. Good delegation means I choose the task on purpose, and discernment means I carefully check every diff before I accept it. In the end, I am accountable for the code, not the agent.

**Example:**  
For example, I ask the agent to update the footer text on all pages of my typing platform in a separate git branch. It changes twenty files in one minute, but I read the diff myself and find one broken link before I merge it.

## 2. Would you allow an AI assistant to change a MikroTik router configuration automatically? Take a position, give a specific router example, and use evaluate, diligence, and confidently.

**Answer:**  
No, I would not let an AI change my router configuration automatically. A router controls the whole network, so one wrong rule can lock me out or open a security hole. I am happy when the AI suggests commands, but I want to evaluate each command before I run it. That is diligence: I check, I test and I keep a backup. Only then can I apply the change confidently.

**Example:**  
If the AI suggests a new firewall rule for my MikroTik, I first export the current configuration as a backup. Then I apply the rule with Safe Mode on, so the router rolls the change back if I lose the connection.

## 3. For drone planning, which is more valuable: fast AI suggestions or careful human checking? Compare them, disagree with one weak approach, and use discernment, accountable, and evaluate.

**Answer:**  
Fast AI suggestions are useful, but careful human checking is more valuable for drone planning. The AI can quickly propose a route, a height and a battery plan. However, it does not see the real place, today's weather or the local rules, so I must evaluate every suggestion with discernment. I disagree with the idea "the AI planned it, so it is safe": the pilot is always accountable for the flight.

**Example:**  
The AI may suggest a straight route that goes over a busy road or near an airport. When I check the map and the no-fly zones in the DJI app, I can change the route before I take off.

## 4. On your typing platform, where has AI collaboration helped most, and where should a human stay in control? Give one feature example and use collaborate, delegation, and diligence.

**Answer:**  
AI collaboration has helped me most with building features quickly, especially the front-end code. I describe what I want, and the AI and I collaborate on the layout and the logic step by step. Smart delegation means I give the AI the coding, but I keep the learning design for myself: what a student should practise and in what order. Diligence also stays with me, because I test every change before real users see it.

**Example:**  
When I added a words-per-minute counter, the AI wrote the timer code in a few minutes. I tested it myself, found a mistake in the formula and asked the AI to fix it.

## 5. Do you agree that collecting better prompts is enough to stay effective with AI tools? Argue your position with one CLI-agent example and use outdated, grounding, and confidently.

**Answer:**  
No, I do not agree. Prompts and tips quickly become outdated, because models and tools change every few months. What stays useful is a grounding framework: I know what to delegate, how to describe the task, how to check the result and how to act responsibly. With this foundation, I can work confidently even with a new tool that I have never used before.

**Example:**  
A prompt trick that worked with an older CLI agent may not help with a newer one. But the habit of giving clear context and reviewing every diff works with any agent.
